# Package index

## All functions

- [`collect_geo_names()`](https://decide-project-eu.github.io/satpoint/reference/collect_geo_names.md)
  : Internal function to extract the names of the geographical
  coordinates from a netCDF file.
- [`collect_variables()`](https://decide-project-eu.github.io/satpoint/reference/collect_variables.md)
  : Utility function to collect all the variable names from an open
  netCDF file.
- [`extract_dates()`](https://decide-project-eu.github.io/satpoint/reference/extract_dates.md)
  : Extract all date or datetimes from an open netCDF file.
- [`extract_geos()`](https://decide-project-eu.github.io/satpoint/reference/extract_geos.md)
  : Extract all geographical coordinates from a netCDF file and convert
  to simple features object.
- [`extract_geos_fvcom()`](https://decide-project-eu.github.io/satpoint/reference/extract_geos_fvcom.md)
  : Extract all geographical coordinates of the nodes from a fvcom
  netCDF file and convert to simple features object.
- [`extract_nodes_fvcom()`](https://decide-project-eu.github.io/satpoint/reference/extract_nodes_fvcom.md)
  : Extract the values for the node variables present in an fvcom netCDF
  file.
- [`extract_site_grids_fvcom()`](https://decide-project-eu.github.io/satpoint/reference/extract_site_grids_fvcom.md)
  : Extract a specific variable from a fvcom format netCDF file for all
  provided geographical locations.
- [`extract_site_grids_nc()`](https://decide-project-eu.github.io/satpoint/reference/extract_site_grids_nc.md)
  : Extract all variable values from netCDF file for all provided
  geographical locations.
- [`filter_dates()`](https://decide-project-eu.github.io/satpoint/reference/filter_dates.md)
  : Internal function to assist the user in extracting only particular
  dates from the results of a netCDF file.
- [`get_nc_data()`](https://decide-project-eu.github.io/satpoint/reference/get_nc_data.md)
  : Internal function to extract the variable values from an open netCDF
  file.
- [`site_buffers()`](https://decide-project-eu.github.io/satpoint/reference/site_buffers.md)
  : Creates circular buffers around site locations to allow for
  different spatial averaging to occur when the values are extracted
  from a netCDF file.
